# Architecture Plan: Clone-Based Project Setup

## Overview & Goals

Vibecode'un proje oluşturma akışı `/vibe-scaffold` yerine clone tabanlı çalışıyor:

```
git clone <vibecode-repo> <yeni-proje-ismi>
cd <yeni-proje-ismi>
rm -rf .git README.md
claude
```

**Hedef:** Bu akış sonrasında ilk `claude` oturumunda Serena ve Context7 **restart gerekmeden** çalışmalı.

## Kök Neden Analizi

`.mcp.json` dosyası `.gitignore`'da olduğu için clone'a dahil olmuyor. Claude başladığında MCP server tanımı bulamıyor → Serena başlatılamıyor.

Mevcut `/vibe-go` komutu `.mcp.json` yoksa oluşturup "restart et" diyor — gereksiz ek adım.

## Değişiklikler

### 1. `.mcp.json`'ı git'e dahil et

**Dosya:** `.gitignore` (root)

Değişiklik: `.mcp.json` satırını kaldır.

```diff
 # OS
 .DS_Store
 Thumbs.db
 
-# MCP config (auto-generated by /vibe-go and /vibe-plan)
-.mcp.json
-
 # Worktrees (temporary)
 .claude/worktrees/
```

**Neden:** Clone sonrası `.mcp.json` hazır olacak → ilk oturumda MCP server'lar başlayacak → Serena çalışacak.

### 2. `session-start.sh` — git init otomasyonu

**Dosya:** `.claude/hooks/session-start.sh`

Git kontrol bloğunun başına ekle:

```bash
# 0. Auto git-init if no .git (fresh clone with deleted .git)
if [[ ! -d "$PROJECT_ROOT/.git" ]]; then
  git -C "$PROJECT_ROOT" init -q 2>/dev/null
  git -C "$PROJECT_ROOT" add -A 2>/dev/null
  OUTPUT+="GIT: auto-initialized (fresh project)"$'\n'
fi
```

**Neden:** `.git` silindikten sonra git features çalışmıyor. Session start'ta otomatik init yapmak tüm git bağımlı kontrolleri aktif eder.

### 3. `session-start.sh` — project_name güncelleme

**Dosya:** `.claude/hooks/session-start.sh`

Git init bloğundan sonra ekle:

```bash
# 0b. Update .serena/project.yml project_name if still "vibecode"
SERENA_YML="$PROJECT_ROOT/.serena/project.yml"
if [[ -f "$SERENA_YML" ]]; then
  DIR_NAME=$(basename "$PROJECT_ROOT")
  CURRENT_NAME=$(grep -m1 'project_name:' "$SERENA_YML" | sed 's/.*: *"\(.*\)"/\1/')
  if [[ "$CURRENT_NAME" == "vibecode" && "$DIR_NAME" != "vibecode" ]]; then
    sed -i '' "s/project_name: \"vibecode\"/project_name: \"$DIR_NAME\"/" "$SERENA_YML"
    OUTPUT+="SERENA: project_name updated to \"$DIR_NAME\""$'\n'
  fi
fi
```

**Neden:** Clone sonrası `project_name` hâlâ "vibecode". Dizin isminden otomatik güncellenmeli.

### 4. `/vibe-go` — MCP check sadeleştirme

**Dosya:** `.claude/commands/vibe-go.md`

Step 0.1'deki `.mcp.json` kontrol bloğu:

```diff
-1. **Check `.mcp.json`** — If it does NOT exist in the project root, create it:
-[...create block...]
-If the file was just created, tell the user: "`.mcp.json` created — session restart needed..."  Then **STOP**.
+1. **Check `.mcp.json`** — Should already exist (tracked in git). If missing for any reason, create it and WARN: "`.mcp.json` was missing and recreated — restart session for MCP servers." Then **STOP**.
```

**Neden:** `.mcp.json` artık repo'da olduğu için "her seferinde oluştur" yerine sadece fallback olarak kalsın.

### 5. `/vibe-plan` — Aynı sadeleştirme

**Dosya:** `.claude/commands/vibe-plan.md`

Step 0.1'de aynı değişiklik.

### 6. CLAUDE.md — Workflow güncelleme

**Dosya:** `CLAUDE.md`

Quick Reference bölümünü güncelle:

```diff
-New project?          →  /vibe-scaffold → /vibe-plan → /vibe-go
+New project?          →  clone → rm -rf .git README.md → claude → /vibe-go
 Existing project?     →  /vibe-go [task]
```

Session Startup bölümüne ekle:

```markdown
### New Project Setup (Clone Workflow)

1. `git clone <vibecode-repo> <project-name>`
2. `cd <project-name>`
3. `rm -rf .git README.md`
4. Run `claude` — Serena and Context7 will be available immediately
5. `/vibe-go [first-task]` to begin

> `.git` is auto-initialized by session-start hook. Project name is auto-detected from directory.
```

### 7. `.serena/project.yml` — dil tespiti uyarısı

**Dosya:** `.claude/commands/vibe-go.md`

Step 0.2'deki language detection bloğu zaten var ve doğru çalışıyor. Ek değişiklik gerekmiyor — sadece `.mcp.json`'ın eksik olmaması yeterli.

## Security Considerations
- `session-start.sh`'daki `sed` komutu sadece `project_name: "vibecode"` → `project_name: "<dirname>"` değiştirir, injection riski yok (dirname zaten mevcut dizin)
- `git init` + `git add -A` sadece `.git` yoksa çalışır, mevcut repo'ya zarar vermez

## Migration Plan

1. `.gitignore`'dan `.mcp.json` satırını kaldır
2. `session-start.sh`'a git init + project_name bloklarını ekle
3. `vibe-go.md` ve `vibe-plan.md` step 0.1'i sadeleştir
4. `CLAUDE.md` workflow bölümünü güncelle
5. `.mcp.json`'ı git'e ekle (`git add .mcp.json`)
6. Test: farklı bir dizine clone yapıp `rm -rf .git && claude` ile Serena'nın çalıştığını doğrula
